# Вектор («Летопись Дел»)

Веб-приложение для управления задачами организации, справочниками, документами, отчетами и рабочим чатом.

## Возможности

- Вход под одной из преднастроенных ролей.
- Список задач с фильтрацией, приоритетами, сроками и ответственными.
- Детальная карточка задачи с чек-листом, прогрессом и связанными документами.
- Ведение справочников подразделений, контрагентов и ролей.
- Реестр нормативных документов со статусами жизненного цикла.
- Серверный режим: PostgreSQL, защищенные сессии, серверные права, общий чат, аудит и хранение вложений.
- Автономный режим IndexedDB для локальной работы и переноса ранее накопленных данных.

## Запуск

В среде с Node.js выполните:

```bash
pnpm install
pnpm dev
```

После запуска откройте адрес, который выведет Vite (обычно `http://localhost:5173`).

## Сборка

```bash
pnpm build
```

## Полноценный сервер

Все команды выполняются из корня проекта. Production-контур запускается через Docker Compose:

```bash
cp .env.server.example .env
# замените пароли и COOKIE_SECRET в .env
docker compose up -d --build
```

После запуска приложение доступно на `http://SERVER_IP`. Для публичного сервера обязательно подключите HTTPS и установите `COOKIE_SECURE=true`.

Подробная инструкция, перенос IndexedDB и резервное копирование описаны в `BACKEND_DEPLOYMENT.md`.
